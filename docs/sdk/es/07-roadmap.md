# 7. Hoja de ruta

*[Read in English](../07-roadmap.md)* · [Índice del SDK](README.md)

Nada de esta página existe todavía. Está aquí para que sepas hacia dónde van los addons, y para que no escribas código
contando con ello hoy. Las ideas y los votos son bienvenidos en los
[issues](https://github.com/Aruvaro-Chulvi/OfflinedAddons/issues).

| Previsto | Qué aportaría |
|---|---|
| **Permisos** | El campo `permissions` limitaría de verdad lo que un addon puede llamar, y Offlined preguntaría al usuario antes de instalar («este addon quiere leer tus contactos»). |
| **Una API `offlined` estable** | Una pequeña librería JavaScript con versiones para addons (almacenamiento, archivos, la IA local, Wikipedia, mapas, calendario) en lugar de los endpoints internos de Offlined. |
| **Archivos propios** | Una carpeta por addon para archivos (no solo un objeto JSON), que sobreviva a la desinstalación si el usuario quiere. |
| **IA local** | Pedirle texto al modelo de lenguaje local, con el consentimiento del usuario. |
| **Más lugares** | Addons que añadan una tarjeta a Inicio, un botón a una sección o una página a Ajustes, y no solo un panel en el menú Addons. |
| **Eventos** | Recibir un aviso cuando algo cambie en Offlined (un evento nuevo en el calendario, un archivo añadido…). |
| **Actualizaciones automáticas** | Offlined avisando al usuario cuando un addon instalado del catálogo tenga una versión nueva. |
