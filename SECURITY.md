# Security policy

*Español abajo.*

Addons run inside Offlined with the same access as the app, so security reports matter a lot to us.

## Reporting

**Please do not open a public issue** for a security problem. Report it privately through GitHub:
[**Security → Report a vulnerability**](https://github.com/Aruvaro-Chulvi/OfflinedAddons/security/advisories/new).

Useful to include: the addon and version (or the part of Offlined), what an attacker could do, and the steps to
reproduce it. You will get an answer as soon as possible; if the problem is confirmed, the addon is withdrawn
from the catalogue or fixed, and you are credited if you wish.

## In scope

- An addon in the catalogue that reads, changes or sends data it should not.
- A way to install a modified package as if it were signed, or to make Offlined install a catalogue package from
  somewhere else.
- A way for an addon panel to escape its iframe or its folder.

## Supported versions

Only the addons in the [latest release](https://github.com/Aruvaro-Chulvi/OfflinedAddons/releases/latest) are
supported.

## Español

Los addons funcionan dentro de Offlined con el mismo acceso que la propia app: los avisos de seguridad nos
importan mucho. **No abras una issue pública**: avisa en privado desde
[**Security → Report a vulnerability**](https://github.com/Aruvaro-Chulvi/OfflinedAddons/security/advisories/new),
con el addon y su versión, qué podría hacer alguien con el fallo y cómo reproducirlo. Si se confirma, el addon se
corrige o se retira del catálogo, y se te reconoce si quieres.
