# 👋 Hello World

*Template — copy this folder to `addons/<your-id>/` and make it yours.*

A tiny example addon: a counter that remembers its value, in Offlined's light or dark theme and in the user's
language.

## What it does

- Shows a counter with two buttons, *Add one* and *Reset*.
- Saves the value in the addon's own storage (`/api/addons/hello-world/storage`), so it is still there the next
  time you open it — and after an update.

## Data it uses

Only its own storage. It calls no other Offlined endpoint and makes no requests to the internet.

## Libraries

None.
